# dependencies.txt — RepoKit's external-tool dependency manifest.
#
# The single source of truth for the external programs RepoKit's
# LOCAL checks call (the scripts in tools/checks/). RepoKit itself
# ships only wiring — these programs are installed by the
# development environment (e.g. the devbox image bakes them in at
# build time, pinned from THIS file's values). When a check gains a
# new external dependency, the change lands here in the same commit
# as the check that needs it; environments compare this manifest
# against what they actually installed and surface drift loudly
# instead of letting a check silently skip (devbox: warned at
# session start, fix offered at exit / via `dev-agent
# --sync-tooling`). Nothing ever installs from this file at check
# time — no check in this toolkit downloads anything at run time.
#
# Format — one tool per line, pipe-separated, five fields:
#   name | kind | version | sha256 | notes
#   name     the tool's name as environments record it
#   kind     binary (a release archive installed as-is) | pip (a
#            Python package installed into the environment)
#   version  the exact pinned version
#   sha256   for kind=binary: BOTH release-archive checksums as
#            amd64=<sha256>;arm64=<sha256> (dpkg architecture names,
#            matching the ARG suffixes environments pin); taken from
#            the project's official release checksums file and
#            verified against the downloaded archives when pinned.
#            For kind=pip: empty (the package index serves the
#            pinned version; environments may add hash pinning).
#   notes    free text: asset-name quirks, provenance, caveats.
# Lines starting with # are comments; blank lines are ignored.
#
